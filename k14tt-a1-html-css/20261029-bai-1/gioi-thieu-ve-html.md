## Giới thiệu về HTML

HTML (Hyper Text Markup Language) - Ngôn ngữ đánh dấu siêu văn bản.

- Là ngồn ngữ dùng để xây dựng trang web.
- Một trang web thông thường gồm có 3 thành phần chính:

* Dữ liệu của trang web (văn bản, âm thanh, hình ảnh...).
* Các thẻ (tag) HTML dùng để định dạng dữ liệu thô hiển thị trên trình duyệt.
* Các đoạn mã CSS dùng đê thêm thuộc tính, màu sắc,... để trang trí trang web.

## Cấu trúc thẻ HTML:

```html
<tên_thẻ>: thẻ mở </tên_thẻ>: thẻ đóng
```

Cú pháp:

```html
<tên_thẻ thuộc_tính="giá_trị">nội dung</tên_thẻ>
```

Ví dụ:

```html
<html></html>
<p align="center">Xin chào</p>
<p></p>
```

## Cấu trúc file HTML

Các file HTML có định dạng file `.html`.

## Thẻ HTML cơ bản

1. Thẻ `<title>`
   Hiển thị nội dung tiêu đề của trang web trên tab trình duyệt.
   Cú pháp:

```html
<title>Xin chào</title>
```

2. Các thẻ heading
   Khai báo tiêu đề trên trang web. Có 6 loại heading kích thước nhỏ dần từ 1 -> 6.
   Cú pháp:

```html
<h1>Nội dung text h1</h1>
<h2>Nội dung text h2</h2>
<h3>Nội dung text h3</h3>
<h4>Nội dung text h4</h4>
<h5>Nội dung text h5</h5>
<h6>Nội dung text h6</h6>
```
